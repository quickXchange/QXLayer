Phase two is accepted.

Now work ONLY on the customer-facing Private Label Website.

Do NOT redesign the Super Admin or Client Admin in this phase.

Goal

Transform the existing shared tenant website into an extremely polished, modern, premium crypto/fintech website.

This is the website that an end customer will see when they visit a Private Label client's domain.

The visual quality should feel like a premium 2026 fintech/crypto product — not a generic template, admin dashboard, or simple landing page.

IMPORTANT:

Do NOT copy QuickXchange.

Do NOT reuse QuickXchange's layout, widget design, components, colors, animations, or visual identity.

Create a completely original Private Label visual system.

---

1. One Master Website

Keep ONE shared customer-facing frontend.

Do NOT create separate website code for Aster, Nexa, or future tenants.

The same frontend must dynamically load:

- Brand name
- Logo
- Favicon
- Primary color
- Secondary color
- Accent color
- Glow color
- Font
- Light/Dark mode
- Hero content
- Enabled modules
- Assets/networks
- Support information
- Social links
- Legal content

from the current tenant configuration.

A tenant must look substantially branded differently without creating a frontend fork.

---

2. Overall Visual Direction

Create a premium futuristic fintech aesthetic.

Use:

- Deep layered backgrounds
- Sophisticated gradients
- Soft animated lighting
- Controlled glow
- Glass / translucent surfaces where appropriate
- Fine borders
- Large modern typography
- Strong whitespace
- Premium iconography
- Smooth micro-interactions
- High-quality transitions
- Subtle depth
- Animated background elements

Avoid:

- Cheap neon effects
- Excessive glow
- Gaming-style design
- clutter
- excessive glassmorphism
- giant empty sections
- generic crypto templates
- excessive animation

The website must still feel trustworthy enough to handle financial transactions.

---

3. Animated Landing Page Background

The landing page should feel alive.

Create lightweight animated visual elements such as:

- Slowly moving gradient lights
- Soft floating light orbs
- Subtle grid/network patterns
- Small blockchain-style nodes
- Gentle particles
- Slowly moving background lines
- Mouse-reactive lighting on desktop where appropriate

Animations must remain subtle and premium.

Never allow animation to interfere with reading or using the exchange widget.

Respect "prefers-reduced-motion".

Reduce expensive effects automatically on mobile.

Performance is more important than decorative animation.

18. Performance

This is critical.

Do NOT make the site heavy just to achieve the premium visual effect.

Prefer:

GPU-friendly animations

constant expensive blur/repaint effects

Lazy-load below-the-fold content where appropriate.

The exchange widget and hero must become interactive quickly.
