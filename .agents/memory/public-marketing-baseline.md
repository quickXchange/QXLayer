name: Public marketing catalog without Production writes
description: Why public advertising may ship with code while operational Production recovery remains blocked.
---

Public marketing content can be published with the application to repair the
otherwise-empty landing catalog without granting owner access or initializing
Production business data. It must reflect reviewed current Development public
content, not historical seeds, private tenant records or disposable fixtures.

**Why:** The user requested automatic Live repairs without manual Shell/SQL,
database deletion or unverified admin grants. Managed Agent Production SQL
remains read-only, and copying the whole Development database is not approved.

**How to apply:** Keep this strictly presentation-only and explicitly identify
its source. Existing Production catalog records, including a hide-all
configuration, must override bundled advertising. Database errors must remain
errors, not be disguised as successful recovery. Preserve unpriced commercial
values and sandbox/planned readiness. Do not describe this as restoring the
database, editable operator configuration or full Live functionality. Publishing
still requires the user's approval; owner restoration still needs a verified
Production identity and an authorized write path.
