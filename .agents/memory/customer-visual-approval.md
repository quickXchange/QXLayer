---
name: Customer website visual approval
description: The customer-facing design must be approved before any new backend phase begins.
---
Wait for the user's explicit visual approval of the shared customer website before starting any new backend phase. Visual approval alone does not request or authorize that next phase.

**Why:** The user rejected the earlier sandbox/SaaS-template appearance and requested an extremely premium crypto/fintech design with five specific tenant/theme screenshots for approval.

**How to apply:** Treat backend architecture, entitlements, plans, isolation, admin applications and non-executing sandbox behavior as fixed during visual iterations. Honest sandbox notices remain necessary, but the financial engine being deferred is not a reason to use a development-template visual design.
